Transaction entry examples

The target is who paid or received the funds. Benefits lists everyone the transaction should be allocated to; it does not automatically include the target.

Shared expense

Expense · $100 groceries · Paid by Bob · Benefits: Bob and Alice

Personal income

Income · $2,000 paycheck · Received by Bob · Benefits: Bob

Shared expense refund

Refund · $20 returned item · Received by Bob · Benefits: Bob and Alice · Link the original expense. It reduces expenses rather than counting as income.

Gift card redeemed for someone else

Income · $50 gift card · Received/redeemed by Bob · Benefits: Alice. This allocates the value to Alice, so the group balance can show Bob owes Alice.
